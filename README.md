# AUREN — Creative & Digital Studio

Primera versión funcional de la página principal de AUREN.

## Ejecutar
Abre `index.html` en un navegador o usa Live Server en VS Code.

## Publicar
Sube `index.html` y la carpeta `assets` a un repositorio público de GitHub. En Settings > Pages selecciona Deploy from a branch, `main`, `/ (root)`.

## Pendientes antes de lanzamiento
- Sustituir `hola@auren.example` por el correo real y conectar WhatsApp o formulario.
- Incorporar fotografías reales y proyectos autorizados (la tarjeta VIGO es una representación conceptual).
- La demo Before & After en la página es una ilustración interactiva, no una instalación Shopify real.
- Revisar textos, enlaces, aviso de privacidad, SEO y dominio.
- Validar con Areli la descripción de servicios de marketing y alcances comerciales.

## Estructura
`index.html` / `assets/css/style.css` / `assets/js/main.js`.
